# Gin & Greeny · 婚礼请柬

2027 年 1 月 2 日，上海花园饭店百花厅。请柬包含中英双语邀请语、两张婚纱照、地图入口和出席回执。

## 上传到 GitHub

解压后，把文件和目录放在仓库根目录，让 `index.html`、`package.json` 和本说明位于同一层。请保留隐藏目录 `.openai/`，构建脚本会读取其中的配置。仓库设为 Private 时，婚纱照的源文件也仅向有权限的人开放。

## 在电脑上预览

在项目目录使用 Node.js 24 运行以下命令，然后打开 http://localhost:4173 。

```sh
npm run dev
```

本地预览用内存数据库试填回执，重启服务会清空本地测试记录。

## 正式收集回执

GitHub 用来保存源码。GitHub Pages 只提供静态托管，正式收集回执需要后端。现有版本通过 Sites 托管，使用名为 `DB` 的 D1 绑定持久保存数据。上传 GitHub 后，对原请柬的修改仍须通过 Sites 发布才会生效。

运行 `npm run build` 可生成 Worker 入口 `dist/server/index.js`。数据库结构在 `drizzle/0000_replies.sql`。宾客在请柬内提交或修改回执，站点所有者在已部署网站的 `/admin` 登录查看汇总。线上管理权限依赖 Sites 验证登录身份，单独迁移到其他主机时需接入对应的身份验证。

## 常用文件

- `index.html` 包含中英文邀请语、婚礼时间、地址和回执表单。
- `style.css` 控制手机与桌面版式和字体。
- `photos/` 存放两张婚纱照。
- `fonts/` 存放当前文案使用的中文字体子集及授权说明。新增汉字时，可更新子集以保持字体一致。
- `guest.js`、`routes.mjs` 和 `admin.html` 分别处理回执表单、后端请求和汇总页面。
